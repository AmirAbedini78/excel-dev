# ERPSMART — AI Development Documentation

این Repository یک حافظه توسعه زنده برای ادامه کنترل‌شده پروژه دارد.

قبل از هر تغییر مرتبط با AI/Accounting از این فایل شروع نکن؛ از این مسیر شروع کن:

```text
docs/ai/00-START-HERE.md
```

منبع حقیقت به ترتیب اولویت:

1. Source و تست‌های Repository
2. Runtime/Live evidence
3. `docs/ai/*`
4. مستندات قدیمی `docs/*.md`
5. تاریخچه گفتگوها

اگر کد و مستند ناسازگار بودند، کد/تست معتبر اولویت دارد و SmartDocs باید همان Task به‌روزرسانی شود.
