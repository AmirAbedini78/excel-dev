## Bugs reproduced (v10.18.0)

| ID | Defect | Evidence |
|---|---|---|
| A1 | `uq_o2c_delivery_line` blocked second partial invoice on same delivery line | Unique index + domain INSERT |
| A2 | O2C draft `invoice` could be confirmed/reserved/delivered | `confirmOrder`/`requireFulfillableStatus` accepted all invoices |

## Fixes

- A1: Replace unique with `uq_o2c_invoice_line (workspace,invoice_doc,sales_line)` + SUM ≤ delivered + invoice idempotency + link-row locks
- A2: `BILLING_NOTE_MARKER` + `isBillingDocument()`; confirm/reserve/deliver/UI reject billing docs
- A3: `erp_o2c_stock_locks` upsert + `FOR UPDATE` before availability revalidation
- A4: Idempotency + `request_hash` lookup before quantity gates; mismatched payload rejected
